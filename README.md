# Better ONE CHAMPIONSHIP Player

This script enhances the ONE CHAMPIONSHIP video player (https://live.onefc.com/video/*) by adjusting the opacity of the language selector, hiding the mouse cursor during video playback and with other features (listed below).

## Installation
1. You need a plugin installed in your browser to run this script on live.onefc.com opening. This script uses [Tampermonkey](https://www.tampermonkey.net/).
2. Create a new script in Tampermonkey
3. Erase the new script content
4. Paste the content of `tampermonkey.js` inside of your new script
5. Save the script
6. Enjoy!

## Features

- Play/Pause on Space
- Play/Pause on Video click
- Mute/Unmute on M key press
- Volume Up/Down on arrows Up/Down press
