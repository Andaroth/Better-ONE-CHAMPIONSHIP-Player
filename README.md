# Better-ONE-CHAMPIONSHIP-Player

This script enhances the ONE CHAMPIONSHIP video player by adjusting the opacity of the language selector and hiding the mouse cursor during video playback.

## Installation
1. You need a plugin installed in your browser to run this script on live.onefc.com opening. This script uses [Tampermonkey](https://www.tampermonkey.net/).
